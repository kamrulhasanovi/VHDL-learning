# VHDL Learning Journey

## About This Repository

This repository contains my VHDL learning journey, from basic logic gates to sequential circuits and simulation experiments.

I am learning digital design concepts and practicing how to write, simulate, and test VHDL code.

## Topics Covered

- Basic logic gates
- Combinational circuits
- Multiplexers and adders
- D flip-flops and JK flip-flops
- Registers and shift registers
- VHDL processes and signal assignments
- Transport and inertial delays
- Testbenches and waveform analysis
- Synthesizable vs. non-synthesizable VHDL

## Tools Used

- VHDL
- ModelSim
